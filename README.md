# Retail Sales Analytics Dashboard — Power BI

## Project Overview
An interactive Power BI sales analytics dashboard built using a star-schema model to analyze revenue, orders, customers, products, regions, segments, payment performance, and month-over-month trends.

The report is structured around:
- `FactSales`
- `DimDate`
- `DimProduct`
- `DimCustomer`

## Dashboard Pages
1. **Executive Overview** — core commercial KPIs and high-level sales trends
2. **Product Analysis** — product sales, quantity, selling price, and product rankings
3. **Product Detail** — drill-through style product performance view
4. **Customer Analysis** — customer, segment, region, and customer-ranking analysis
5. **Product Tooltip** — contextual product KPIs
6. **DAX Practice** — supporting measures and DAX validation work

## Key KPIs & Measures
The report contains measures including:
- Total Sales
- Total Orders
- Total Customers
- Average Order Value
- Total Quantity
- Average Selling Price
- Paid Sales %
- Month-over-Month Growth %
- Previous Month Sales
- Running Sales
- Sales YTD
- Product Rank
- Customer Rank
- Sales % of Total
- Average Sales per Customer
- Average Sales per Order

## Analytical Features
- Monthly sales trend analysis
